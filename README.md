# Atlas OS

Base de desenvolvimento do Atlas OS, organizada como um monorepo com pnpm e Turborepo.

## Estrutura

- `apps/api`: futura aplicação de API.
- `apps/web`: futura aplicação web.
- `packages/config`: configurações compartilhadas.
- `packages/types`: tipos compartilhados.
- `docs`: documentação do produto e da arquitetura.
- `infrastructure`: recursos de infraestrutura e ambientes.
- `tests`: testes de integração e ponta a ponta.

## Próximo passo

Instale as dependências com `pnpm install`. As aplicações ainda não foram implementadas.
