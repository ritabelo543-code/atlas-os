# Atlas OS Roadmap

## v0.2 — Plataforma de Inteligência

- Painel Atlas Operation para saúde, auditoria e configuração segura.
- Contratos v2 para conhecimento e decisões auditáveis.
- Infraestrutura de memória com retenção simples.
- Registros iniciais de agentes e plugins futuros.
- Seleção segura de provider de IA com fallback para Mock.

## v0.3 — Autonomous Intelligence Platform

- Atlas Executive Agent e Agent Runtime.
- Memória com decay, prioridade, favoritos e referências cruzadas.
- Knowledge e Decision Engine v3.
- Permission Manager, Plugin Runtime e plugin GitHub read-only.
- Mission Control operacional para agentes, memória, plugins, eventos e performance.

## v0.4 — Colaboração

- Autenticação local e isolamento multiusuário.
- Persistência transacional SQLite com migração dos JSON.
- Busca semântica local por vetores de termos/bigramas.
- Operação autenticada e sessões de usuário.

## v0.5 — Produção

- Autenticação federada, recuperação de conta e rotação de sessões.
- PostgreSQL para implantação distribuída.
- Embeddings e avaliação de busca semântica.
- Observabilidade, quotas e administração de organizações.
